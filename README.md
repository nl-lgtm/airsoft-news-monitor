# Airsoft News Monitor — бесплатный сайт + сбор по кнопке

Не нужен Python на вашем компьютере. GitHub Actions запускает Python на сервере GitHub по запросу, сохраняет JSON в репозитории, а сайт на GitHub Pages показывает ленту.

## Настройка (один раз)

1. Создайте бесплатный аккаунт на https://github.com (если его ещё нет).
2. Создайте **публичный** репозиторий `airsoft-monitor` с веткой `main`. Публичный репозиторий означает, что новости и исходный код доступны всем; **секретов в проекте нет**.
3. Загрузите в корень репозитория **все файлы и папки** из архива, включая скрытую папку `.github/workflows/collect.yml`. В интерфейсе GitHub можно использовать Add file → Upload files; убедитесь, что путь `.github/workflows/collect.yml` сохранился.
4. В Settings → Actions → General → Workflow permissions установите **Read and write permissions** (если пункт доступен). Сохраните.
5. В Settings → Pages → Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/(root)` и сохраните.
6. Откройте `https://ВАШ_ЛОГИН.github.io/airsoft-monitor/`. Если репозиторий называется иначе, URL изменится.
7. Нажмите **Запустить сбор**. Откроется GitHub Actions. Выберите **Run workflow → Run workflow**. Дождитесь зелёной галочки (иногда несколько минут). Вернитесь на сайт и нажмите **Обновить ленту**.

## Как работает

- Первый запуск: публикации за 7 дней. Следующие: с момента последней **успешной** проверки конкретного бренда с запасом 12 часов.
- Новости берутся из **Google News RSS**, а не напрямую с сайтов производителей. Полнота и релевантность не гарантируются. Ссылки могут вести через Google News.
- Если источник недоступен, `last_success` не обновляется. Ошибка сохраняется в JSON.
- Удаление дублей по URL; смысловые дубли пока могут оставаться.
- История хранится в `data/news.json` в GitHub. Личные отметки «опубликовано» сохраняются только в браузере.
- Редактор постов пока **шаблонный**, не ИИ; фото и квадратный экспорт ещё не подключены.
- Если основная ветка называется не `main`, измените её в `index.html` и настройках Pages.

## Ограничения

- **Одна кнопка прямо на статическом сайте не может безопасно запустить GitHub Actions без авторизации.** Поэтому «Запустить сбор» открывает страницу Actions, где владелец репозитория нажимает Run workflow. Не вставляйте GitHub Personal Access Token в HTML.
- Сайт, открытый локально двойным кликом, требует вручную заполнить `const REPO = 'ВАШ_ЛОГИН/airsoft-monitor';` в `index.html`. На GitHub Pages адрес определяется автоматически.
- GitHub Actions/Pages имеют лимиты и правила использования, которые могут меняться.
- Изменение ветки, приватности и прав может потребовать дополнительной настройки.
